# DRC-YOLO26 A0–A7 三随机种子测试分析报告

## 结论摘要

本轮 A0–A7 已全部完成（每个实验种子 `0/1/2` 各一次，共 24 次训练和对应的最佳权重测试）。以原始 YOLO26-N（A0）为基线，**完整 DRC-YOLO26（A7）没有带来总体检测精度提升，不能作为下一阶段的主模型**：

| 对比 | P | R | mAP50 | mAP50-95 |
|---|---:|---:|---:|---:|
| A0 原始 YOLO26-N | 82.69 ± 0.85 | 77.10 ± 0.47 | 84.03 ± 0.51 | 49.87 ± 0.16 |
| A7 完整 DRC-YOLO26 | 83.30 ± 0.57 | 77.36 ± 0.09 | 83.52 ± 0.34 | 49.60 ± 0.26 |
| A7 − A0（百分点） | +0.61 | +0.26 | **−0.51** | **−0.28** |

其中 A7 相对同种子 A0 的 mAP50-95 差值为 `[-0.45, +0.19, -0.57]` 个百分点：仅 seed1 上升，seed0 与 seed2 均下降。因此，A7 的 P/R 小幅变化不能视为 AP 提升证据。

总体 mAP50-95 均值最高的是 A6（SDR + CCQ，49.96%，较 A0 +0.09 个百分点），但其三种子配对差值为 `[-0.20, +0.39, +0.07]` 个百分点，增量远小于种子波动，且 mAP50 下降 0.22 个百分点。因此 A6 只能保留为**待验证候选**，不能宣称优于基线。

## 2. A0–A7 对应结构配置

| 实验 | 实际结构配置 | 关键改动 |
|---|---|---|
| A0 | 原始 YOLO26-N，P3/P4/P5 `Detect` | 基线：标准首层 `Conv`、标准 PAN concat、标准端到端 Detect。 |
| A1 | A0 + `CDRStem` | 用 CDRStem 替换首个 RGB stride-2 Conv：对手色表征、双尺度高通、细节可靠性图、上下文/细节路由；辅助分支以零缩放初始化。 |
| A2 | A0 + `SDRFusion` | 将 P3 融合处的标准 concat 改为 `SDRFusion([top-down P3, backbone P3, P2], reduce_ratio=0.25)`；P2 仅作细节注入，不增加 P2 检测头。 |
| A3 | A0 + `CCQDetect` / `CCQE2ELoss` | 在 one-to-one 分支增加质量头；使用 one-to-many 共识教师、可靠性加权条件框蒸馏与质量校准。配置为 `box_gain=0.5`、`quality_gain=0.5`、`quality_beta=0.5`、`tau=0.2`、`delta=0.02`、`l1_gain=0.25`、`hard_neg_topk=128`、`hard_neg_gain=0.25`。 |
| A4 | A1 + A2 | CDRStem + SDRFusion，检测头仍为标准 `Detect`。 |
| A5 | A1 + A3 | CDRStem + CCQDetect/CCQE2ELoss。 |
| A6 | A2 + A3 | SDRFusion + CCQDetect/CCQE2ELoss。 |
| A7 | A1 + A2 + A3 | 完整 DRC-YOLO26：CDRStem + SDRFusion + CCQDetect/CCQE2ELoss。 |

组合实验 A4/A5/A6 使用运行目录内固化的 YAML；A0/A1/A2/A3/A7 使用项目内对应 YAML。每一个 seed manifest 均保存 YAML SHA-256 和四个 DRC 代码文件哈希，避免训练过程受后续代码修改影响。

## 5. 模块级归因与交互判断

| 结构对照 | 可观察到的三种子趋势 | 结论 |
|---|---|---|
| A1 vs A0：CDR | 总体 P +1.00，但 mAP50 −0.40、mAP50-95 −0.14；三次 mAP50-95 均不高于同种子 A0。 | 当前默认 CDRStem 不应进入下一轮主干候选。 |
| A2 vs A0：SDR | 总体 mAP50-95 与 A0 基本相同；scallop +1.0、holothurian +0.4，但 echinus −0.7、starfish −0.6。 | 有类别选择性价值，值得单独细化，而不是直接宣称总体提升。 |
| A3 vs A0：CCQ | R 在三次种子中都提高（总体均值 +1.07），P 和 mAP50 下降，mAP50-95 持平。 | CCQ 改变了检出/置信度权衡，但现有参数未改善排序与定位 AP。 |
| A4 vs A0：CDR + SDR | R +0.89，但 P 的 SD 达 1.75（A0 为 0.85），mAP 不提升。 | CDR 与 SDR 的组合引入不稳定性。 |
| A5 vs A0：CDR + CCQ | mAP50-95 三个种子全部下降，且 mAP50 三个种子全部下降。 | 最明确的负交互；下一轮不应复用该组合。 |
| A6 vs A0：SDR + CCQ | mAP50-95 两次正增益、均值 +0.09；但 mAP50 −0.22，P 波动升至 1.25。 | 仅可作为“待确认”候选；需要更多种子和逐图统计。 |
| A7 vs A0：完整组合 | P/R 小增，mAP50 −0.51、mAP50-95 −0.28；三类（echinus、starfish、holothurian）mAP50-95 下降。 | 模块效应不具加性，拒绝完整 DRC 作为当前改进结论。 |

## 6. 排序与可执行决策

以主要指标 mAP50-95 的三种子均值排序：

1. A6（SDR + CCQ）：49.96 ± 0.15，**候选但未确认**。
2. A2（SDR）：49.87 ± 0.17，与 A0 持平。
3. A3（CCQ）：49.87 ± 0.08，与 A0 持平。
4. A0（原始 YOLO26-N）：49.87 ± 0.16，**当前唯一稳健基线/主模型**。
5. A4（CDR + SDR）：49.84 ± 0.13。
6. A1（CDR）：49.73 ± 0.09。
7. A5（CDR + CCQ）：49.68 ± 0.19。
8. A7（完整 DRC）：49.60 ± 0.26。

推荐的模型选择结论：

- **主结论：**当前 DRC-YOLO26 A7 相对原始 YOLO26-N 没有提升，不能用于替换基线。
- **保留对象：**A2（用于 scallop/holothurian 的细节注入假设）和 A6（需严格复验的组合候选）。
- **暂停对象：**默认 CDRStem，以及任意直接包含 `CDR + CCQ` 的新组合；其已有数据明确不支持继续扩大实验。

## 7. 供 GPT 规划下一步时使用的约束与建议

请以以下事实为输入，而非以“DRC 已提升”为前提：

1. 目标不是继续堆叠模块，而是在 A0 之上获得可重复的 mAP50-95 提升，同时不牺牲 echinus 与 starfish 的 AP。
2. 下一步优先做已有矩阵中的**受控组件消融**：SDR 的 S1–S5，以及 CCQ 的 Q1–Q5。它们可以分别检验 P2 细节路由、可靠性门控、共识教师、条件门控、可靠性权重与质量分支，避免再次把多个未知因素混在 A7 中。
3. 若需要调参，应先围绕 CCQ 的 `quality_beta`、`quality_gain`、`box_gain`、`hard_neg_topk`、`hard_neg_gain` 与 `delta` 做小范围、单因素或正交的候选筛选；原因是 A3 稳定提高 R 却未提高 AP，说明当前质量分支/分数校准并未把更多召回转化为更优排序。
4. 若优先解决难类，应从 SDR 的 P2 细节路径切入，因为 A2 的 scallop 与 holothurian 有正向 AP 信号；验证条件应加入“echinus 与 starfish mAP50-95 不低于 A0 的容忍界限”。
5. 下一轮必须保存每图预测或完整 `Metric` 原始数组，并输出：总体及每类 P/R/mAP50/mAP50-95、APs/APm/APl、三个 seed 的均值/SD/范围、与 A0 同种子的配对差值以及 bootstrap CI。否则无法把极小均值差异和随机波动区分开。
6. 最终确认前应设置独立 `images/test`，避免当前 `test=val` 的模型选择偏差。
